# Постановка

## Хакатон

* Первый ИИ-хакатон Газпром ЦПС, 18.09.2026, 09:00–14:00 МСК, онлайн.
* Кейс 4 «Экзит-интервью»: HR-аналитик (Inference Engine), который за минуту превращает
  сырой текст беседы в структурированный паспорт проблемы для дашборда топ-менеджмента.
* Команда №1: Вадим Крысин, соло.
* Работа над MVP 10:00–12:45, питч-сессия 13:00–13:30, питч 5 минут.
* Критерии: глубина парсинга 30%, качество инсайта 25%, UX и скорость 15%,
  архитектура 15%, креативность 15%. Антипаттерны: красивый дашборд без логики,
  «средняя температура», галлюцинации.

## Что строим

> Сервис «Паспорт ухода»: загружаешь транскрипт экзит-интервью, через минуту получаешь
> паспорт проблемы из пяти полей, где каждый факт подтверждён цитатой, найденной в
> исходном тексте программно; десяток паспортов складывается в дашборд системных проблем.

Компоненты:

1. **Конвейер анализа** (`backend/app/domain/exit_interview/`): разбор реплик → настроение
   по репликам → извлечение паспорта моделью по жёсткой JSON-схеме → проверка цитат по
   источнику → сохранение. Без модели работает правило-ориентированный запасной путь.
2. **Экран «Интервью»**: список паспортов, карточка с подсветкой цитат в оригинале,
   график настроения по ходу разговора, отметки отклонённых цитат, выгрузка DOCX.
3. **Дашборд**: причины ухода, частота болей по всем интервью, зоны риска, граф связей
   между проблемами, метрика «было / стало».

Промпты лежат в `prompts/*.txt`, правятся без пересборки. Модель локальная (Ollama)
или любой OpenAI-совместимый API, выбор через `.env`.

## Демонстрационный сценарий

1. Открыть «Загрузка», выбрать transcript.txt (в том числе скрытый кейс жюри).
2. Через несколько секунд открывается паспорт: причина, боли с частотой, сильные стороны
   с цитатами, риск, три гипотезы.
3. Клик по цитате подсвечивает фрагмент в оригинале. Показать факт, который модель
   предложила, а проверка отклонила.
4. График настроения по репликам.
5. Дашборд по всем интервью: топ болей компании, граф связей.
6. «Было / стало»: 40 минут ручного разбора против секунд сервиса.
