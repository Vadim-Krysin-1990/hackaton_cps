# Слайды питча (7 слайдов по структуре брифа, 5 минут)

Речь на 5 минут лежит в `питч.md`. Здесь текст, который стоит на слайдах.

## 1. Титул
**Паспорт ухода**
Exit-интервью → паспорт проблемы → дашборд для руководства
Первый ИИ-хакатон Газпром ЦПС · 18.09.2026 · кейс 4 · команда №1, Вадим Крысин

## 2. Задача и решение
Слева, задача: интервьюер записывает беседу в текст, аналитика «на глаз», реакция на системную проблему с опозданием на 2–3 месяца.
Справа, что умеет:
01 Транскрипт .txt → паспорт из пяти полей за 10 секунд
02 Каждый факт подтверждён цитатой, найденной в тексте программно
03 Настроение по репликам: что говорит и что чувствует
04 Дашборд по всем интервью: частота болей, риски, связи, что делать

## 3. Как делали: агентный подход
Постановка → ИИ → генерация → проверка → сборка
* Человек: правило «нет цитаты в тексте — нет факта», порядок слотов, что режем.
* Агент целиком: синтетика (12 бесед), конвейер, проверка цитат, экраны, тесты, README.
* Где агент ошибся и как поймали: словарь настроения ловил «ад» внутри слов; запасной путь записал похвалу в боли (92 % интервью, поймано по дашборду); рассуждающая модель тратила токены на размышления, половина бесед падала в запасной путь (поймано по полю «движок»).
* QA параллельно с разработкой: проверка цитат написана вторым шагом, до экранов. Тесты после каждого слота: 21 зелёный.

## 4. Почему это можно внедрять
Безопасность: открытая модель через Ollama, данные не покидают контур; транскрипты анонимны; журнал «кто, когда, что, сколько».
Ландшафт: Python + FastAPI + React, SQLite, запуск одной командой, Docker; модель меняется в .env; та же схема паспорта при любой модели.
Люди и перенос: промпты в текстовых файлах, HR правит без разработчика; сопровождает HR-аналитик; переключатель моделей: малая 20B для контура, большая для спорных случаев.

## 5. Эффект
Формула: (норматив ручного разбора − время сервиса) × число интервью
40 мин − 9 с ≈ 40 мин на беседу · 12 бесед демо = 8 часов
Главное не минуты: системная проблема видна в день загрузки, а не через квартал.
Качество: 77 цитат проверено, 77 подтверждены, 0 выдуманных фактов.
