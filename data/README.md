# data/

Рабочие данные сервиса. **Содержимое не коммитится** — на большинстве хакатонов
материалы ТЗ конфиденциальны, а выгрузки заказчика тем более.

```
data/
├── samples/    демонстрационные наборы (генерируются скриптом)
├── uploads/    загруженные через интерфейс датасеты
├── docs/       загруженные документы библиотеки
├── qdrant/     встроенный векторный индекс
└── app.db      база SQLite
```

Демонстрационный набор:

```bash
python backend/scripts/make_demo_data.py data/samples/demo.xlsx --rows 500
```
