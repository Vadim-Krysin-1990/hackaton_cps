# Чек-лист сдачи

Проходится за день до дедлайна, не в последний час.

## Работоспособность

- [ ] `docker compose up -d --build` на чистой машине поднимает сервис
- [ ] Демонстрационные данные загружаются скриптом из репозитория
- [ ] Основной сценарий отрабатывает за приемлемое время, время измерено
- [ ] Сервис работает без интернета (если этого требует регламент)
- [ ] `cd backend && python -m pytest tests -q` — зелёные
- [ ] `cd frontend && npm run build` — без ошибок типов
- [ ] `/api/health` показывает состояние базы, модели и эмбеддингов

## Данные и безопасность

- [ ] Датасеты и материалы ТЗ не попали в git (проверить `git log --stat`)
- [ ] Секреты не в репозитории: `APP_SECRET_KEY`, пароли, ключи API
- [ ] Демо-пароль изменён, если стенд доступен снаружи
- [ ] Вход и роли работают; если требовали единый вход — Keycloak поднят
- [ ] Персональные данные обезличены или отсутствуют

## Упаковка

- [ ] README: что это, как запустить, откуда данные, что внутри, границы применимости
- [ ] Презентация по шаблону организатора
- [ ] Видео демонстрации, уложенное в регламент
- [ ] Метрика «было / стало» видна в самом продукте, а не только на слайде
- [ ] Репозиторий вычищен: нет мусора, временных файлов, чужих архивов
- [ ] Инструкция развёртывания проверена на машине, где ничего не стоит

## Защита

- [ ] Демо-сценарий отрепетирован по времени
- [ ] Есть запасной план на случай отказа сети или модели
- [ ] Готовы ответы: почему так, что не сделали и почему, что дальше
- [ ] Известно, кто говорит, кто показывает, кто отвечает на вопросы
