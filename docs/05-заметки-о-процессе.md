# Заметки о процессе (для слайда «Как делали: агентный подход»)

Хронология 18.09.2026, МСК. Вся разработка велась в Claude Code, руками код не писался.

## До старта (09:25–09:55)

* Кейсы известны только по заголовкам. Агент оценил четыре кейса по названиям и
  предложил SmartLMS. **После появления полных ТЗ рекомендацию пересмотрел сам**:
  SmartLMS требует генерацию видео с TTS, за 2 ч 45 мин соло нереально. Выбран
  экзит-интервью как самый завершаемый и проверяемый.
* Решение человека: подтвердить выбор кейса, дать сигнал жюри «креатив приветствуется»
  и «малые модели повышают шанс внедрения» → в план добавлен переключатель моделей.

## Что декомпозировал человек

* Правило конвейера: факт без цитаты, найденной в тексте, в паспорт не попадает.
* Порядок слотов: каркас → синтетика → конвейер → проверка → экраны → модель → упаковка.
* Что режем: Keycloak, дообучение, Telegram-бот, несколько моделей одновременно.

## Что агент сделал целиком

* Синтетический генератор из 12 транскриптов (банки фраз по четырём сценариям ухода,
  два формата записи: с подписями реплик и сплошным текстом).
* Предметный модуль: разбор реплик, словарь настроения, запасной путь без модели,
  проверка цитат по схожести, конвейер с повтором при невалидном JSON.
* API, три экрана, два новых графика (линия настроения, граф связей), тесты, README.

## Где агент ошибся и как поймали

1. **Подстановка промпта через `str.format`** ломалась на фигурных скобках в тексте
   беседы. Поймано при чтении кода до первого запуска, заменено на явную замену плейсхолдеров.
2. **Словарь настроения**: короткий маркер «ад» срабатывал внутри слов «задачи», «кладут».
   Поймано по странным маркерам в отладочном выводе; короткие ключи ищутся как слова.
3. **Запасной путь** записывал «коллеги отличные» в боли категории «команда и климат»
   (92 % интервью). Поймано по дашборду: доля выглядела неправдоподобно. Фразы с
   маркерами похвалы исключены из поиска болей.
4. **Порядок тестов**: новый файл тестов логинил сессию раньше проверки «без входа → 401».
   Поймано красным тестом каркаса, файл переименован.
5. **Рассуждающая модель gpt-oss** тратила лимит токенов на размышления: половина
   интервью уходила в запасной путь, ответы по 30–50 с. Поймано по полю «движок» в
   списке. Лечение: `format=json`, `think=low`, лимит 3000 токенов → 6–11 с, JSON с первой попытки.
6. **Малая модель путает причину ухода** с первой жалобой и занижает риск при фразе
   «двое уже ходят по собеседованиям». Поймано глазами на паспорте, уточнены правила в промпте.

## Анализ и QA параллельно с разработкой

* Проверка цитат спроектирована и написана вторым шагом, до экранов: всё, что модель
  выдаёт, проходит через неё с первого запуска.
* Тесты каркаса гонялись после каждого слота; предметные тесты добавлены до подключения модели.
* Каждый паспорт хранит шаги конвейера, заметки и отчёт проверки — их видно в карточке.
